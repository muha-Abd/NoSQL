# Вариант 3 — Библиотека и история выдач (Java + MongoDB)

Проект для IntelliJ IDEA с Maven. MongoDB Compass используется для просмотра базы и коллекций, а Java-приложение подключается к MongoDB Server.

## Что реализовано
- `books`, `readers`, `loans`;
- создание книг, выдача и возврат, удаление записи выдачи;
- история выдач читателя и поиск просрочек;
- поиск книг по названию, список доступных книг;
- агрегации популярности книг и количества выдач по жанрам;
- индексы;
- 30 книг, 15 читателей, 45 синтетических выдач;
- 3 интеграционных теста.

## Запуск в IntelliJ IDEA
1. Установите JDK 17 или новее, IntelliJ IDEA и MongoDB Community Server.
2. Запустите службу MongoDB на `mongodb://localhost:27017`.
3. Откройте IntelliJ IDEA → **Open** → выберите папку проекта с `pom.xml`.
4. Дождитесь загрузки Maven-зависимостей.
5. Откройте `src/main/java/kz/library/LibraryApp.java` и запустите `main`.
6. В консоли выберите `1`, чтобы создать тестовые данные. После этого запускайте приложение повторно и выбирайте нужные операции.

## Просмотр в MongoDB Compass
1. Откройте Compass и подключитесь к `mongodb://localhost:27017`.
2. Откройте базу `library_nosql`.
3. Внутри появятся коллекции `books`, `readers`, `loans`.
4. Во вкладке Documents можно посмотреть документы; в Indexes — созданные индексы.
5. Для проверки выдач откройте `loans`. Поля `book` и `reader` — вложенные snapshot-данные на момент выдачи.

## Демонстрационные запросы
1. Каталог книг с сортировкой по названию.
2. Поиск книг по части названия.
3. История выдач читателя по `reader.readerId`.
4. Просроченные активные выдачи.
5. Популярные книги через `$group`, `$sort`, `$limit`.
6. Количество выдач по жанрам через `$group`.
7. Список книг без активной выдачи.
8. Создание книги.
9. Выдача книги читателю.
10. Возврат и удаление выдачи.

## Тестирование
В IntelliJ запустите `LibraryAppTest` или выполните в терминале:
```bash
mvn test
```
Тесты требуют запущенный MongoDB Server и используют базу `library_nosql_test`.

## Важно
Пункт `1` очищает и заново заполняет коллекции `books`, `readers`, `loans` в базе `library_nosql`. Используйте его только для учебных данных. MongoDB Compass — графический клиент; сервер MongoDB должен быть установлен и запущен отдельно.
